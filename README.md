# Clinic Management Database System

A clinic database system designed using ERD and implemented with SQL to manage clinic operations efficiently.

---

## Project Overview

This project represents a relational database system for a clinic environment. The system helps organize and manage:

* Patients
* Doctors
* Appointments
* Prescriptions
* Payments
* Rooms

The database was designed using ERD concepts and implemented using SQL.
